# GP Score Log 利用ガイド

このガイドでは、GP Score Logのインストールから、プレー結果の記録、バックアップ、困ったときの対処までを説明します。

## このアプリでできること

GP Score Logは、DDR GRAND PRIXのリザルト画面を読み取り、プレー結果をパソコンに記録します。記録した結果は、自己ベストやプレー履歴として確認できます。

個人スコアは利用者のパソコン内に保存され、外部サービスへ自動で送信されません。

### 対応しているプレー

- DDR GRAND PRIXのグランプリプレー
- SINGLE（SP）とDOUBLE（DP）
- ゲーム画面の大きさ: 1280×720
- Windows 11

「アーケードプレミアムプレー」および「アーケードノーマルプレー」は、認識・自動保存の対応対象外です。

## ダウンロードとインストール

1. [最新版のダウンロードページ](https://github.com/tts1374/ddrgp_scorelog/releases/latest)を開きます。
2. Windows用のセットアップファイル `com.tts1374.ddrgp_scorelog-win-Setup.exe` をダウンロードします。
3. ダウンロードしたファイルを開き、画面の案内に従ってインストールします。
4. インストールが終わると、通常はGP Score Logが自動で起動します。

アプリの利用に必要なものはセットアップファイルに含まれています。.NETやPythonなどの開発用ソフトを別に入れる必要はありません。

### Windowsから警告が表示された場合

現在のセットアップファイルには発行元のデジタル署名がないため、Windows SmartScreenなどの警告が表示されることがあります。ダウンロード元がこのプロジェクトのページであることを確認できた場合だけ、インストールを続けてください。

## はじめて起動したとき

初回起動では、スコアの読み取りに使う楽曲・譜面データと、個人スコアを保存する場所が自動で準備されます。

起動後に「データ管理」を開くと、次の状態を確認できます。

- 個人スコアデータ
- 楽曲・譜面データ
- 収録されている譜面数
- 最後にスコアを保存した日時

すでに個人スコアがある場合、アプリが内容を勝手に上書きしたり修復したりすることはありません。利用できないデータが見つかった場合は、理由を表示して使用を止めます。

## プレー結果を記録する

1. DDR GRAND PRIXを起動します。
2. ゲーム画面の大きさを1280×720にします。
3. GP Score Logを起動します。
4. 「アプリ起動時に監視を開始」がON（初期設定）の場合は、ゲーム画面が見つかるまで待ちます。
5. 自動で始まらない場合は、GP Score Logの画面または画面右下の通知領域から`監視開始`を押します。
6. 通常どおりプレーします。リザルト画面が表示されると、読み取れた結果が自動で記録されます。

ゲームを起動する前にGP Score Logを起動しても問題ありません。ゲーム画面が見つかるまで待機します。

### 監視を一時停止・再開する

- 一時停止するには`監視停止`を押します。
- 再開するには`監視開始`を押します。
- 自分で停止したあとは、同じ起動中に勝手に再開することはありません。

監視中、ゲーム画面の周囲にWindowsの枠が表示されることがあります。この枠が表示されていても、それだけで読み取りに失敗しているわけではありません。

### アプリの画面を閉じたとき

- 右上の×を押してもアプリは終了せず、画面右下の通知領域に残ります。
- 通知領域のGP Score Logをダブルクリックすると、画面をもう一度開けます。
- アプリを完全に終了するには、通知領域のメニューから`終了`を選びます。

## 記録できる結果・できない結果

誤ったスコアを残さないため、リザルト画面が表示されただけでは記録しません。次の情報を十分に読み取れた結果だけを記録します。

- 曲と譜面
- スコア、判定数、MAX COMBO、EX SCORE、ランク、クリア状況など
- 同じプレーがすでに記録されていないこと
- 個人スコアデータへ正しく書き込めること

記録に成功したプレーは、ホーム、自己ベスト、楽曲・譜面詳細、プレー履歴に表示されます。

### 記録できなかった場合

必要な情報を読み取れなかった場合は、次のお知らせが表示されます。

> 自動保存できないプレーが発生しました。正式DBには保存されていません。

お知らせ内の「正式DB」は、個人スコアの保存先を指します。

このお知らせが表示されても、それまでに記録したプレーが消えたり、書き換わったりすることはありません。次のプレーの監視も続きます。

設定でこのお知らせをOFFにしても、読み取れなかった結果を記録しない動作は変わりません。

## 各画面の使い方

### ホーム

今日のプレー数、自己ベストを更新した回数、フルコンボ数、最近のプレーを確認できます。保存済みのプレーがまだない場合は、次に行う操作が表示されます。

### 自己ベスト

SINGLEまたはDOUBLEを選び、難易度、レベル、曲名、バージョン、ランク、クリア状況などで譜面を絞り込めます。

譜面を選ぶと、詳しい記録を開けます。まだプレーしていない譜面も一覧に表示され、記録がない項目には`—`が表示されます。

### 楽曲・譜面詳細

選んだ譜面の通常スコアBEST、EX SCORE BEST、ランク、クリア状況、FLARE、プレー回数、スコアの変化、保存済みの全プレーを確認できます。

### プレー履歴

保存済みのプレーを、日時、曲名、プレイスタイル、難易度、レベルなどで検索できます。プレーを選ぶと、判定数、MAX COMBO、保存日時などの詳細を確認できます。

## 設定を変更する

設定画面で項目を変更したら、`変更を保存`を押してください。

| 項目 | 初期設定 | できること |
| --- | --- | --- |
| アプリ起動時に監視を開始 | ON | 起動後にゲーム画面を自動で探します。 |
| 保存できない結果を通知 | ON | 記録できなかったときのお知らせを表示します。 |
| 既定のプレイスタイル | SINGLE | 自己ベストを開いたときに最初に表示するスタイルを選びます。 |
| 起動時に表示する画面 | ホーム | 起動後に最初に表示する画面を選びます。 |
| 言語 | 日本語 | 日本語、英語、韓国語から選びます。 |

`初期値に戻す`を押すと、画面上の項目が最初の設定に戻ります。そのあと`変更を保存`を押すと反映されます。

### 表示言語を変える

言語の変更を保存すると、アプリは安全に処理を終えてから自動で再起動します。自動で再起動しない場合は、画面の案内に従って手動で起動してください。

初めて使うときは、Windowsの表示言語に合わせて日本語、韓国語、または英語が選ばれます。

## データ管理

`データ管理`では、保存済みのプレー数、自己ベストがある譜面数、最後に保存した日時、楽曲・譜面データの状態を確認できます。ここから個人スコアのバックアップと復元も行えます。

### 個人スコアをバックアップする

1. `データ管理`を開きます。
2. `バックアップを作成`を押します。
3. 保存先を選びます。
4. 作成されたJSONファイルを、アプリ本体とは別の安全な場所に保管します。

バックアップに含まれるのは、保存済みのプレー履歴です。アプリの設定や楽曲・譜面データ、動作ログは含まれません。

### バックアップから復元する

復元すると、現在の個人スコアはバックアップの内容に置き換わります。念のため、復元前にも現在のデータをバックアップしてください。

1. `データ管理`を開きます。
2. `バックアップから復元`を押します。
3. 復元するJSONファイルを選びます。
4. 内容の確認結果を読み、確認画面で続行します。

壊れたファイルや対応していないファイルは復元されません。復元に失敗しても、現在の個人スコアは変更されません。復元が終わると、プレー履歴と自己ベストが更新されます。

## アプリと楽曲・譜面データの更新

### アプリ本体の更新

配布版のアプリは、起動後に新しい版がないか自動で確認します。更新が見つかると、ダウンロード、アプリの終了、再起動を自動で行います。

インターネットに接続できない場合や更新に失敗した場合は、現在の版をそのまま使用できます。個人スコア、設定、楽曲・譜面データ、動作ログは変更されません。

### 楽曲・譜面データの更新

起動時に、新しい楽曲・譜面データがないか自動で確認します。必要なファイルがすべて正しいことを確認してから入れ替えます。

更新に失敗した場合は、これまでの楽曲・譜面データをそのまま使用します。個人スコアと設定は変更されません。インターネット接続が戻ったあとにアプリを再起動すると、もう一度確認します。

## アプリの終了とアンインストール

アプリを完全に終了するには、画面右下の通知領域にあるGP Score Logのメニューから`終了`を選びます。右上の×は、画面を隠すだけです。

アプリをアンインストールしても、個人スコアや設定などはパソコンに残ります。保存場所は次のフォルダーです。

`%LOCALAPPDATA%\DDRGpScoreViewer`

このフォルダーには、個人スコア、設定、楽曲・譜面データ、動作ログが含まれます。データも削除したい場合は、先に必要なバックアップを作成し、不要なことを確認してから、このフォルダーを手動で削除してください。

## トラブルシューティング

### ゲーム画面を見つけられない

次の順に確認してください。

1. DDR GRAND PRIXが起動しているか確認します。
2. ゲーム画面の大きさが1280×720になっているか確認します。
3. DDR GRAND PRIXの画面を複数開いている場合は、1つにします。
4. 以前に`監視停止`を押した場合は、`監視開始`を押します。

### 楽曲・譜面データを更新できない

インターネットに接続できることと、パソコンの空き容量を確認してください。更新に失敗しても、現在の楽曲・譜面データと個人スコアはそのまま使えます。しばらくしてからアプリを再起動してください。

### アプリを更新できない

インターネットに接続できることと、パソコンの空き容量を確認してください。更新に失敗しても、現在の版と個人スコアはそのまま使えます。しばらくしてからアプリを再起動してください。

### 楽曲・譜面データに異常があると表示される

ファイルを個別に入れ替えたり、個人スコアを手動で修復したりせず、同じダウンロードページから配布された正しいデータを使用してください。

### 監視中にエラーが表示される

ゲーム画面を1280×720に戻すか、DDR GRAND PRIXを再起動してください。そのあと、GP Score Logの停止処理が終わってから`監視開始`を押します。途中だったプレー結果が誤って記録されることはありません。

### 記録できない結果が続く

画面に表示された理由を確認してください。それまでのプレー履歴は変更されません。必要であれば、次のリザルト画面で再度お試しください。

詳しい調査が必要な場合、動作ログは次の場所にあります。

`%LOCALAPPDATA%\DDRGpScoreViewer\logs\gp-score-log.log`

### バックアップを復元できない

選んだJSONファイルが途中で編集されたり、壊れたりしていないか確認してください。復元に失敗しても、現在の個人スコアは変更されません。現在のデータをバックアップしてから、別のファイルを選び直してください。

## 既知の制限

- Windows 11、DDR GRAND PRIX、ゲーム画面1280×720での利用を対象としています。
- 主な動作確認はSINGLEで行っています。
- 「アーケードプレミアムプレー」および「アーケードノーマルプレー」は、認識・自動保存の対応対象外です。
- セットアップファイルに発行元のデジタル署名がないため、Windowsから警告が表示されることがあります。
- オンラインへのバックアップ、記録できなかった結果の手動修正、通知履歴の表示には対応していません。
- 自分で監視を停止したあとは、`監視開始`を押すまで再開しません。
